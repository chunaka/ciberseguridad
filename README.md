# Repositorio de Ciberseguridad

Repositorio personal de notas, writeups y resúmenes de habilidades a partir de laboratorios prácticos de ciberseguridad (TryHackMe, HackTheBox, entre otros). El objetivo es documentar mi proceso de aprendizaje en pentesting ofensivo, metodología y herramientas, sirviendo también como portafolio técnico.

## Aviso y alcance

- Todo el contenido se basa en actividad realizada en entornos de laboratorio autorizados (TryHackMe, HackTheBox u otras plataformas educativas), nunca contra sistemas sin autorización explícita.
- No se publican flags, respuestas, credenciales, claves, hashes ni walkthroughs paso a paso de contenido activo en ninguna plataforma. Cuando una plataforma lo permite (por ejemplo, rooms o máquinas marcadas como retiradas en el caso de TryHackMe), se pueden incluir writeups más detallados; en los demás casos, el contenido se limita a resúmenes de metodología, herramientas y lecciones aprendidas.
- Este repositorio tiene fines educativos y de documentación personal. El uso de las técnicas aquí descritas fuera de entornos autorizados es responsabilidad exclusiva de quien las aplique.

## Estructura del repositorio

Por ahora la estructura es simple: una carpeta por plataforma, y dentro un archivo `.md` por cada laboratorio o room.

```
.
├── README.md
└── TryHackMe/
    └── basic pentesting.md
```
